Enable Public Sharing

Review before proceeding

One-time download required

The cloudflared binary (~30 MB) will be downloaded from github.com/cloudflare/cloudflared and saved to bin/cloudflared inside your project. Subsequent starts use the cached binary instantly.

cloudflared is already cached locally — tunnel will start immediately.

  • cloudflared is Cloudflare's open-source tunneling tool. It creates a secure, encrypted HTTPS tunnel from your local Iris Engine to a temporary public *.trycloudflare.com URL accessible from anywhere.

  • No account required. Cloudflare Quick Tunnels are free and anonymous — no sign-in or configuration needed.

  • The tunnel is active only while this server is running. It tears down automatically on shutdown and the public URL changes each session.

  • Anyone with the generated URL can reach your API. Protect it with an API key if your server should not be publicly accessible.
